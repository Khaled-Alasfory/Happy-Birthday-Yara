# Birthday Website – GitHub Pages

All images, audio, and video are placed in the repository root so the site can be uploaded directly.

## Files
- index.html
- style.css
- script.js
- image-01.jpg ... image-11.jpg
- song.mp3
- birthday-video.mp4

## GitHub Pages
Upload all files to the root of your repository, then enable GitHub Pages from Settings → Pages → Deploy from a branch → main → / (root).
